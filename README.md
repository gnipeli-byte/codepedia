# コードペディア (Codepedia)

架空のWeb学習者向けの学習リソース・掲示板サイトです。
アコーディオンUI・投稿の検索/書き込み/削除機能を持つ、フロントエンド完結型のWebアプリです。

## デモ

GitHub Pagesで公開中: (公開後にURLをここに貼る)

## 技術スタック

- HTML / CSS / JavaScript (jQuery)
- レスポンシブ対応なし版・アコーディオンUI(CSSトランジション)
- 投稿の書き込み・検索・削除機能(フロントエンドのみで完結、配列操作で実装)

## PHP / MySQL版について

`php-version` フォルダに、PDOを使ったPHP/MySQL版のコード一式を置いています。
GitHub PagesはPHPを実行できないため、こちらは動作デモとしては公開していませんが、以下の実装をコードとして確認いただけます。

- PDOによるDB接続、プリペアドステートメントを使ったSQLインジェクション対策
- トランザクション処理(登録・削除)
- Ajaxによるカテゴリ連動のセレクトボックス

## こだわった点

- CSSトランジション+SVGアイコン(開閉インジケーター)によるアコーディオンUI(画像アセット不要)
- カード要素にSVGアイコンを使用し、視覚的な分かりやすさを補強
- jQuery依存を整理し、フロントエンドのみで動く投稿機能(検索・書き込み・削除)を実装
- ブルーバイオレット系×グレーのカラーでプログラミング学習に適した落ち着いた印象を表現しながらも、Kosugi Maruフォントで硬さを和らげている。
